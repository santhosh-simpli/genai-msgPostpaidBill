# MSG Logo

Please save the MSG logo image as `msg-logo.png` in this directory.

The logo should be:
- Format: PNG with transparent background (or the circular yellow background)
- Recommended size: 200x200 pixels or larger
- The logo will be displayed in:
  - Login page header (96x96 pixels)
  - Main dashboard header (64x64 pixels with yellow circular background)

If the logo file is not found, the application will gracefully hide the logo placeholder and continue to work normally.
